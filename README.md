EMPLOYEE ATTRITION ANALYSIS (IBM HR DATA) | Orange | PSPP | Logistic Regression

Cleaned and validated an HR dataset of 1,470 employee records, checking missing values and data types, and found an overall attrition rate of 16.1%.
Explored attrition patterns using distributions and box plots in Orange, and found that leavers were younger, lower-paid (avg. monthly income 4,787 vs 6,833) and more often single.
Ran significance tests in PSPP (p < 0.05) and ranked predictors, keeping key drivers such as Age, Monthly Income, Distance From Home, Marital Status and Job Satisfaction.
Built a logistic regression model on a 70:30 train-test split (AUC 0.745). Balancing the classes raised recall from 9.9% to 70.4%, so the model flags 7 in 10 actual leavers.
Recommended retention actions for HR: support early-career and single employees, review pay for at-risk salary bands, and improve job satisfaction and work-life balance.
